# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment,
personal attacks and discriminatory language aren't accepted in issues, pull requests or any other project space.

Report unacceptable behavior privately to the maintainer through their [GitHub profile](https://github.com/uditkumar01).
Reports are handled confidentially; the maintainer may remove comments or block contributors who break these rules.
